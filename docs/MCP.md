# 외부 도구 연결

현재 플러그인은 파일·Git·터미널만으로 동작하므로 MCP 서버를 번들하지 않는다. 빈 서버나 임의 endpoint를 설치하지 않는다.
GitLab 이슈·사내 DB·업무 API가 필요하면 실제 서버 URL과 인증 방식, 필요한 도구를 정한 후 호스트의 MCP 설정 또는 플러그인 연결 설정으로 등록한다.
자격증명은 Git에 넣지 않는다. 기존 호스트 연결을 우선 사용하고 스킬에는 필요한 도구와 입력·출력만 정의한다.
MCP 서버는 외부 기능 제공자이며 SDLC 작업을 반복 실행하는 별도 에이전트 엔진이 아니다.
